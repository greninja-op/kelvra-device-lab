## 1. Executive Summary

The Artifact Management Subsystem (`src/artifact_manager.py`) provides unified, secure, and structured persistence for all binary and textual outputs generated by Device Lab operations. This includes captured screenshots, screen recording MP4s, logcat export text/JSON dumps, and automation execution reports.

---

## 2. Directory Layout & Storage Partitioning

All artifacts reside strictly within the project's root `artifacts/` folder, partitioned into dedicated subdirectories based on payload classification:

```
artifacts/
├── catalog.json             # Persistent atomic metadata registry
├── screenshots/             # Static verification frames (JPEG / PNG)
│   └── art-7f9a1c83d2e4_screenshot_MOCK_01.jpeg
├── recordings/              # Screen recording videos (MP4)
│   └── art-89f412ba78c9_rec_5b72e10a.mp4
├── logs/                    # Scrubbed logcat exports (TXT / JSON)
│   └── art-1248aef01928_logcat_export.txt
└── reports/                 # Automation workflow execution manifests (JSON)
    └── art-30819fa00bc1_report_exec-91a0b3c.json
```

## 3. Security: Path Traversal Defense

User-supplied filenames (such as those derived from device labels or workflow steps) present path traversal risks. The `ArtifactManager` enforces multi-layer sanitization:
1. **Filename Sanitization:** The filename is extracted using `Path(name).name`, stripping leading and trailing directory traversals (`..`, `/`, `\`). Characters are restricted to alphanumeric symbols, underscores, hyphens, and dots.
2. **Path Anchoring & Resolution:** Target paths are resolved using `.resolve()` and checked against `self.base_dir`:
   ```python
   if not str(target_path).startswith(str(self.base_dir)):
       raise ValueError(f"Security error: Artifact path traversal detected '{target_path}'")
   ```
3. **Safe Serving:** Downloading endpoints verify that the target physical file on disk resides within the authorized storage subtree.

## 5. Deletion Confirmation Guarantee

To prevent accidental data loss, destructive artifact deletion via `ArtifactManager.delete_artifact(artifact_id, confirm=True)` requires explicit confirmation:
- Attempting to delete an artifact with `confirm=False` immediately raises `ValueError("Explicit confirmation required to delete artifact")`.
- When confirmed, both the physical file on disk and the catalog index entry are expunged simultaneously.

---

## 6. REST API Endpoints

- `GET /api/artifacts`: List all stored artifacts with optional `type` and `device_id` filtering.
- `GET /api/artifacts/storage/summary`: Retrieve storage utilization metrics (used bytes, quota bytes, artifact counts).
- `GET /api/artifacts/{artifact_id}/download`: Download physical artifact binary.
- `DELETE /api/artifacts/{artifact_id}?confirm=true`: Permanently delete artifact.
